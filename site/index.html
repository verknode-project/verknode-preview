Visual, node-based data workflows for Python, inside JupyterLab.

Connect nodes on a canvas to read, clean and reshape tables, run statistics and machine learning, draw charts and work with molecules, and see every intermediate result. Or build the workflow by chatting with an agent.

▶ Try the live demo More screenshots

Runs in your browser with nothing to install. The first start takes 15 to 30 seconds.

Build workflows with an agent

Describe what you need. The agent adds, configures and connects nodes, tests them in a sandbox, and asks before removing anything.

Walkthroughs that explain the workflow

A document you step through like a slide show. Its links show the nodes, settings and outputs they name, and its buttons run them.

Widgets on the canvas

Sliders, inputs and charts next to their nodes, updating as you change them. Selections feed the rest of the workflow.

Molecules in 2D and 3D

RDKit molecules as a column type, with Mol* and NGL viewers on the canvas.

Work from the keyboard

Auto layout, alignment, and arrow keys between nodes, with widgets that follow the selection.
